# Tracker Lafay 2026 — version application

## Installation sur GitHub Pages

1. Décompresse ce dossier.
2. Envoie tous les fichiers à la racine de ton dépôt GitHub :
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - dossier icons/
3. Active GitHub Pages sur la branche principale.
4. Ouvre l’adresse GitHub Pages sur tablette.
5. Dans Options, clique sur “Installer l’app”.

## iPad / iPhone

Safari ne montre pas toujours le bouton d’installation.
Utilise : Partage → Ajouter à l’écran d’accueil.

## Android / Chrome

Menu ⋮ → Installer l’application ou Ajouter à l’écran d’accueil.
